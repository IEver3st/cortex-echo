# Changelog

## 1.0.0 (2026-11-13)

### Added
- First release: 24 sounds drawn as marks in the world
- Per-sound shapes and colours, plus red-green, blue-yellow and high-contrast presets
- Off-screen pips for sounds behind you or behind walls, spread apart so two sounds in the same direction never cover each other
- Voice marks sized to each talker's pma-voice range
- ping export and client event for other scripts' sounds
